# Claude Skills — Business

A collection of [Claude](https://claude.ai) skills for business, freelance, and career-facing work: prompt engineering, safe GitHub publishing, professional social content, and job search automation.

## Skills in this repo

| Skill | What it does |
|---|---|
| [`prompt-crafter`](./prompt-crafter) | Turns a vague idea into a structured, reusable prompt (stage/task/rules) ready to paste into another Claude chat. |
| [`git-to-git`](./git-to-git) (aka **GITTOGIT**) | Publishes or updates Claude skills to your own GitHub, straight from the browser (via Claude in Chrome) — no Git command line needed. Runs a mandatory personal-data/API-key scan before every publish, defaults to anonymous authorship, and picks the right repo, license, and `.gitignore` on its own. |
| [`gitfabric`](./gitfabric) | Generates new skill ideas with real GitHub star potential, gets your approval, builds the skill, and hands it off to GITTOGIT to publish. Triggered end-to-end with "ligar a fábrica git" — still pauses for your approval before building and before publishing. |
| [`instagram-brand`](./instagram-brand) | Prepares Instagram posts that promote your GitHub work, with a consistent professional visual identity mirrored from your LinkedIn and minimal personal exposure. Assembles the post in-browser; you always click the final "Share" yourself. |
| [`career-search`](https://github.com/Viniciusvcgprofssional/Career-Search) | (separate repo) Personalizable job/internship search that drives a real browser to search job boards and filters results against your resume. |

## Install a skill

Download the `SKILL.md` (and any `references/`/`scripts/`/`assets/` folder) from the skill's subfolder and add it as a skill in Claude, or point Claude at this repo directly.

## Why these exist

These skills automate the parts of freelance/professional life that are usually repetitive busywork: writing good prompts, safely publishing your own work, growing that portfolio, keeping a consistent professional presence on social media, and finding relevant opportunities.
